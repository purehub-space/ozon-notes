询盘合集

记录每条询盘的来源、客户目标价、我方报价与跟进状态；后续把询盘价格发我，按下面的格式补进顶部数据区即可。

录入说明

  • 每条询盘一个对象，加在文件顶部 const INQUIRIES = [ ... ] 数组里，逗号分隔。
  • 状态取值：待报价 / 跟进中 / 已报价 / 已成交 / 流失；价格字段保留原文（可带币种，如 ¥2.8/只、$0.45/pc、120₽/只）。
  • cost_ref 填对应出厂价盘里的参考单价，方便算利润；link 可填聊天记录 / 商品链接。
