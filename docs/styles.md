# 博客风格样板 V2（供挑选）

上一版偏"文字极简"，这次按你的要求重新全网找了一批——分两条线：**① 设计感强的品牌站 ② 建站平台 / 模板项目**（GitHub 热门 + 专业模板市场）。截图均为整页实拍。

你挑 2–3 个喜欢的，我仿照其风格重建本站（配色 / 布局 / 字体 / 文章排版）。

---

## A. 品牌站（设计感强，适合做"高级感"参考）

### A1 · Linear — 暗色现代 SaaS 品牌

- 风格：**深色 + 渐变光晕 + 圆角卡片**，克制而有高级感
- 特点：Linear 是硅谷顶级产品团队；博客用「分类标签 + 卡片瀑布流」，技术文章配大图
- 适合：AI 工具 / 产品型内容，未来卖产品时气质最搭

![Linear](/blog-styles/linear.png)

### A2 · Raycast — 暗色精选博客

- 风格：**深色 + 大留白 + 头条文章 + 卡片列表**
- 特点：头条文章突出、次级卡片规整，导航丰富；个人开发者工具品牌范本
- 适合：工具实测、产品发布、教程类内容

![Raycast](/blog-styles/raycast.png)

### A3 · Anthropic — 白底大字编辑风

- 风格：**纯白背景 + 超大标题 + 编辑杂志式排版**
- 特点：Claude 官方新闻室；用排版层级和留白营造"专业、可信"
- 适合：深度分析、行业观点、官方声明类内容

![Anthropic](/blog-styles/anthropic.png)

### A4 · Notion — 亮色内容博客

- 风格：**亮色 + 左侧分类栏 + 卡片网格**，插图丰富
- 特点：Notion 官方「Tools & Craft」板块，文章带插画、作者、分类
- 适合：多栏目运营（AI / 跨境 / GEO / 技术），插画风让内容更亲切

![Notion](/blog-styles/notion.png)

## B. 建站平台 / 模板项目（可以直接用，或抄其设计）

### B1 · Ghost — 内容订阅 + 会员变现平台

- 建站：Ghost 6.0，开源内容平台
- 风格：**白底 + 大号标语 + 产品仪表盘展示**；核心理念「把读者变成生意」
- 特点：自带会员 / 付费订阅 / 邮件通讯，**天然适合"内容 + 卖产品"路线**
- 落地：可自托管，或直接用 Ghost 建站替代 VitePress

![Ghost](/blog-styles/ghost.png)

### B2 · Nextra — Next.js/MDX 建站框架

- 建站：Vercel 出品，开源框架（GitHub 6k+ ⭐）
- 风格：**文档站式布局**：导航 + 侧栏 + 正文，双栏清晰
- 特点：写 Markdown 自动成站，支持暗色模式；适合文档 + 博客混合站
- 落地：可无缝迁移现有 VitePress 内容

![Nextra](/blog-styles/nextra.png)

### B3 · Astro Themes — 建站主题市场

- 建站：Astro 官方主题库（社区贡献）
- 风格：**主题聚合页**，覆盖博客 / 作品集 / SaaS 落地页等几十类
- 特点：一站式预览几十种现代博客主题，免费 + 付费都有；**适合在这里挑现成模板**
- 落地：选中某主题后可直接在 GitHub 拿到源码

![Astro Themes](/blog-styles/astro-themes.png)

### B4 · Framer Templates — 专业模板市场

- 建站：Framer（无代码建站平台）
- 风格：**深色模板画廊**，按行业分类（Blogs / AI / SaaS / Agency…），带价格与预览
- 特点：大量视觉出众的博客 / 落地页模板，**适合用来"抄"布局和质感**
- 落地：Framer 免费模板可直接用；付费模板 $99 起

![Framer Templates](/blog-styles/framer-templates.png)

---

> 组合建议：
> - **想要"高级感 + 未来卖产品"**：A1 Linear 或 A2 Raycast 的暗色系
> - **想要"白底专业编辑风"**：A3 Anthropic
> - **想要"直接抄模板、快速落地"**：B1 Ghost 或 B3 Astro Themes 里挑
> - **内容多栏目 + 插画**：A4 Notion
